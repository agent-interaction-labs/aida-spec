# Contributing

## Getting Started

```bash
git clone https://github.com/agent-interaction-labs/aida-spec.git
cd aida-spec
npm install
```

## Development

- **Schema changes:** Edit `schema/draft/schema.json`. Run `npm run validate` to check examples.
- **Specification changes:** Edit files in `docs/specification/draft/`.
- **TypeScript types:** Update `schema/draft/schema.ts` to match schema changes.

## Pull Request Process

1. Fork the repository
2. Create a feature branch
3. Make changes
4. Run validation: `npm run validate`
5. Open a pull request with a clear description

## Code of Conduct

- Be respectful and constructive
- Focus on technical merit
- Assume good faith
